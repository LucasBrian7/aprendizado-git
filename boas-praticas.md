# Boas práticas com Git e GitHub

## 1. Utilizar mensagens claras nos commits

As mensagens dos commits devem explicar de forma objetiva o que foi alterado.

## 2. Organizar o projeto utilizando branches

É importante utilizar branches diferentes para desenvolver novas funcionalidades ou realizar alterações sem modificar diretamente a branch principal.

## 3. Fazer commits pequenos e frequentes

Realizar commits menores facilita o acompanhamento das alterações e permite identificar problemas com mais facilidade.

## 4. Revisar as alterações antes de enviar

Antes de realizar um push, é importante verificar as alterações feitas utilizando comandos como `git status` e `git diff`.
